Blocklet — Maxfiylik siyosati

Oxirgi yangilanish: 2026-yil 3-sentyabr

Blocklet (paket: uz.airsoft.blocklet) — oflayn blok-puzzle o'yini. Ro'yxatdan o'tish yo'q, hisob yaratilmaydi, ism-familiya, elektron pochta yoki kontaktlar so'ralmaydi. Quyida ilova aynan nimalarni yig'ishi to'liq sanab o'tilgan.

Qurilmada saqlanadigan ma'lumot (bizga yuborilmaydi)

O'yin jarayoni — rekord, tangalar, ochilgan temalar, sozlamalar (ovoz, tebranish, til, rang-ko'r rejimi), tugallanmagan o'yin holati — faqat qurilmangizda saqlanadi va hech qayerga yuborilmaydi. Ilova o'chirilsa, bu ma'lumot ham o'chadi.

Firebase Analytics (Google)

O'yinni yaxshilash uchun anonim foydalanish statistikasi yig'iladi:

  • Hodisalar: ilova ochilishi, o'yin boshlanishi va tugashi (ochko, qo'yishlar soni, davomiylik, tozalangan qatorlar, kombo, topilgan tangalar), kombo darajalari, tema ochilishi, tutorial yakuni, sozlama o'zgarishi, reklama so'rovi/ko'rsatilishi/mukofoti.
  • Foydalanuvchi xossalari: birinchi ochilgandan beri o'tgan kun, jami o'yinlar soni, rekord, build turi.
  • Firebase avtomatik yig'adiganlar: qurilma modeli, OS versiyasi, ilova versiyasi, mamlakat darajasidagi taxminiy joylashuv (IP orqali), ilova nusxasi identifikatori (app instance ID).

Firebase Crashlytics (Google)

Ilova qulasa, xatolik hisoboti yuboriladi: crash log (stack trace), qurilma modeli, OS versiyasi, ilova versiyasi, qulash paytidagi qurilma holati. Bu faqat xatolarni tuzatish uchun ishlatiladi.

Google AdMob (reklama)

Ilovada reklama bor (o'yinchi o'zi bosadigan rewarded video va o'yindan keyingi interstitial). AdMob quyidagilarni qayta ishlaydi: reklama identifikatori (Advertising ID), IP asosidagi taxminiy joylashuv, reklama bilan o'zaro ta'sir ma'lumotlari. Yevropa iqtisodiy hududi va Buyuk Britaniyada Google UMP orqali rozilik so'raladi; rozilik berilmasa, moslashtirilmagan reklama ko'rsatiladi. Batafsil: Google reklama texnologiyalari.

Firebase Remote Config

Reklama chastotasi kabi sozlamalarni masofadan boshqarish uchun ishlatiladi. Shaxsiy ma'lumot yig'maydi; texnik jihatdan Firebase o'rnatish identifikatoridan foydalanadi.

Blocklet — Политика конфиденциальности

Последнее обновление: 3 сентября 2026 г.

Blocklet (пакет: uz.airsoft.blocklet) — офлайн блок-пазл. Без регистрации и аккаунтов; имя, e-mail и контакты не запрашиваются. Ниже полностью перечислено, что именно собирает приложение.

Данные на устройстве (нам не отправляются)

Игровой прогресс — рекорд, монеты, открытые темы, настройки (звук, вибрация, язык, режим для дальтоников), незавершённая партия — хранится только на вашем устройстве и никуда не передаётся. При удалении приложения удаляется и он.

Firebase Analytics (Google)

  • События: открытие приложения, начало и конец партии (очки, ходы, длительность, собранные линии, комбо, монеты), уровни комбо, открытие темы, завершение обучения, смена настроек, запрос/показ/награда рекламы.
  • Свойства пользователя: день с первого запуска, всего партий, рекорд, тип сборки.
  • Автоматически Firebase: модель устройства, версия ОС, версия приложения, примерная геолокация на уровне страны (по IP), идентификатор экземпляра приложения.

Firebase Crashlytics (Google)

При сбое отправляется отчёт: crash log (stack trace), модель устройства, версия ОС, версия приложения, состояние устройства в момент сбоя. Используется только для исправления ошибок.

Google AdMob (реклама)

В приложении есть реклама (rewarded-видео по нажатию игрока и interstitial после партии). AdMob обрабатывает: рекламный идентификатор (Advertising ID), примерную геолокацию по IP, данные о взаимодействии с рекламой. В ЕЭЗ и Великобритании согласие запрашивается через Google UMP; без согласия показывается неперсонализированная реклама. Подробнее: рекламные технологии Google.

Firebase Remote Config

Используется для удалённого управления настройками (например, частотой рекламы). Личные данные не собирает; технически использует идентификатор установки Firebase.

Дети

Приложение не предназначено для детей и не адресовано детям младше 13 лет.

Удаление данных и контакты

Blocklet — Privacy Policy

Last updated: September 3, 2026

Blocklet (package: uz.airsoft.blocklet) is an offline block puzzle. There is no sign-up and no account; we never ask for your name, e-mail or contacts. Everything the app actually collects is listed below.

Data stored on your device (never sent to us)

Game progress — best score, coins, unlocked themes, settings (sound, vibration, language, colour-blind mode) and the unfinished game — is stored only on your device and never transmitted. Uninstalling the app deletes it.

Firebase Analytics (Google)

  • Events: app open, game start and end (score, placements, duration, lines cleared, max combo, coins earned), combo milestones, theme unlocks, tutorial completion, settings changes, and ad request/impression/reward events.
  • User properties: days since first open, total games played, best score, build type.
  • Collected automatically by Firebase: device model, OS version, app version, coarse country-level location (from IP), app instance identifier.

Firebase Crashlytics (Google)

If the app crashes, a report is sent: the crash log (stack trace), device model, OS version, app version and device state at the time of the crash. Used solely to fix bugs.

Google AdMob (advertising)

The app shows ads (player-initiated rewarded video and post-game interstitials). AdMob processes the advertising ID, IP-based approximate location and ad interaction data. In the EEA and UK consent is collected via Google UMP; without consent, non-personalised ads are shown. See how Google uses data in ads.

Firebase Remote Config

Used to tune configuration (such as ad frequency) remotely. It collects no personal data; technically it relies on the Firebase installation identifier.

Children

The app is not directed at children and is not intended for children under 13.

Data deletion and contact

Collected statistics are anonymous and not tied to any account. Questions or deletion requests: islomyuldashev3007@gmail.com
